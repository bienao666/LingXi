# 情绪入口使用说明

适用版本 v1.54，服务器 Web＋QQ；本功能调整表达，不作诊断、不授予工具或记忆权限。

## 开启与入口

在“助手管理 → 支持偏好”允许情绪适配、开启自动情绪线索，再选择入口并保存。开启分析或增加入口时，须有当前已验证的记忆抽取模型。关闭或缩小范围不要求模型在线。

| 四字选项 | 处理来源 | 独立条件 |
|---|---|---|
| 网页文字 | 新发的独立 Web 文字 | 默认唯一选中的入口；附件、任务协助和 QQ 会话的 Web 访问不参与 |
| 确认转写 | 浏览器语音核对后点击发送的文字 | 有效语音会话；不是从声音判断心情，连续模式自动发送不参与 |
| 绑定私聊 | 本人 QQ 私聊的直接文字 | 身份双向确认有效、已允许共享本人记忆，并在本页另行选择；不会由此开启绑定或记忆权限 |

自动分析默认关闭。旧偏好缺少入口字段时只允许网页文字，不会自动启用另外两项。开启分析时至少选一个入口；设置不因聊天文本、附件或模型输出改变。

QQ 暂复用已有“本人记忆共享”身份的所有者会话边界，因此仅绑定、未允许共享记忆的私聊仍是隔离身份，不进行本人的情绪分析。群聊和陌生人始终不继承个人偏好。未来若拆分独立私聊主体授权，需要另行设计，不能靠本选项扩大范围。

## 线索与失效

所有入口合计最多每五分钟一次付费分析，使用抽取模型、最多 400 个输出 token。只分析最多 4000 字的当前第一人称表达；引用、假设、角色扮演、他人、历史和诊断类描述保守跳过。失败、未知及中断不自动重放付费分析，普通聊天继续。

异步分析不保证影响同一轮回答；就绪后用于原会话的后续表达。支持页显示来源入口、原文自述／系统推测／本人纠正、原文入口及到期时间。手填有效自述优先；不跨会话分享标签，不进入长期记忆、子助手或主动话题。

线索自原消息时间起默认一小时，可选一至四小时。纠正不续期。更改偏好或关闭入口、否定旧感受、来源删除、身份撤销、渠道配置变更及到期，会禁止后续使用；相关在途生成和旧衍生回答失效。删除源会话仍须在会话管理中单独操作。恢复屏障及备份隔离继续清理线索和手填感受并关闭自动分析。

已显示、复制或交给第三方模型的内容无法保证撤回；QQ 协议已接受的消息也不能据此宣称撤回成功。

## 接口与部署

- `/api/support-preferences` 增加 `observation_channels` 字符串数组，值为 `web_text`、`confirmed_voice`、`qq_private`；有重复值、未知值或启用时为空返回 422。
- `/api/emotion-observations` 返回 `source_kind`；来源失效后不再暴露源消息标识、摘录或入口。旧有效记录缺省为 `web_text`。
- 偏好修改、纠正、撤回、删除沿用认证、CSRF、版本检查和独立删除屏障；模型或插件不能代替确认。
- schema 保持 `0047`；需同时更新 Core、worker、Web，不应仅替换前端或只回退不支持新入口的旧 Core。系统迁移仍要求相同镜像，不把同 schema 当成任意版本兼容。

协议与回归结果见[情绪入口验证记录](./情绪入口验证记录.md)。真实模型准确度、真实 QQ 账号和物理音频体验独立验收，不能用合成标签证明理解心情。
