# 实时转写验证记录（v1.57）

本次范围是手动模式原生流式转写输入，不是完整原生双向语音。开发验证使用合成协议事件、音源与独立数据；未修改用户的供应商或语音配置。

## 已验证

- 转写专用 GA 配置、单语言／语言数组、临时增量、最终稿修订、音频回执来源匹配，拒绝越界和错误协议事件。
- Cookie／CSRF／Origin、单次票据、过期、重复使用、登录与工作区隔离、每人一个活动片段和请求预算。
- 配置、连接、登录、工作区及迁移变更使授权失效；取消不写入聊天、作业或记忆，调用记录不含字幕、录音或密钥。
- 使用实际 TLS WebSocket 服务器验证直连、HTTP CONNECT、HTTPS 代理及 SOCKS5；目标 IP 固定、Host 与 TLS 原域名保留，代理流量确实经过隧道。
- 前端显式开始、定稿后回调、取消、离线、断线、错误、晚到结果和单次完成；8–96 kHz 连续分块重采样保持相位，输出 24 kHz PCM16 且分片有界。
