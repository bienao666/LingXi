# 模型单价与费用统计验证记录

版本 v1.46，2026-10-31。迁移 `0040`。本记录将人工单价估算、协议验证与真实供应商账单区分。

## 使用方法

打开“数据日志 → 用量预算 → 模型单价”，选择模型，填写币种及每百万 token 的输入／输出价格。缓存读取与写入价格可留空；服务返回非零缓存用量但未配置对应价格时，整次费用未知。未配置的价格不默认当作免费，只有明确输入 `0` 才表示零单价。先预览，再勾选理解估算范围并保存；保存检查当前价格和服务连接版本。

同一模型用于不同用途的目录条目分别定价。连接改变后旧价格失效，需重新核对。价格停用后新请求费用未知，已开始请求和历史记录继续使用原快照。当前支持 CNY／USD，分别汇总而不换汇；不自动获取厂商报价。

“用量预算”展示已知估算和未知费用次数，支持按来源渠道、模型、任务和插件分组。各维度是同一批调用的不同视角，不能相加。无持久化关联的调用保留“未关联”，不根据聊天正文推测归属。模型调用记录可查看估算金额、价格版本和原始价格快照。

## 计价与边界

- 请求发出前固定单价，完成、失败或取消时按该快照记录；改单价不回填历史，也不重算正在执行的调用。
- 使用十进制定点运算，保留每次及聚合精度，不用二进制浮点计算金额。缺少完整输入／输出用量、数据矛盾、音频 token 或对应缓存价缺失时，金额为未知；不能用总 token 猜输入／输出比例。
- 成功、失败、取消及模型验证调用均按实际提供的用量记录。失败不等于免费，未知也不当作零。旧记录没有调用前快照，一律保持未知。
- 原有 UTC token 日阈值仍只告警，不停止请求。费用估算不提供支付、扣款、硬金额预算或供应商账单对账。
- 不包含时长／字符语音计费、税费、固定请求费、阶梯价、汇率、额外折扣及第三方插件服务费；用户须填写适用的 token 单价，不能将估算当成最终收费。
- 当前要求完整输入／输出 token 用量；仅返回输入及总量、没有输出数量的嵌入调用仍显示未知，不宣称所有嵌入计费格式均受支持。
- 汇总最多完整扫描所选范围 100,000 次调用，超出拒绝并要求缩小范围；单维分组最多展示 1,000 项，超出明确标注，整体汇总不遗漏。
- 管理接口复用所有者认证、工作区检查、CSRF 和版本冲突。诊断导出只保留汇总及摘要化模型／任务／插件编号，不导出价格配置中的凭据（价格本身不含凭据）或业务正文。

新增接口 `GET /api/admin/model-prices` 与 `PUT /api/admin/model-prices/{identity}`；后者要求价格版本、服务连接版本和 `acknowledgement=estimate_only`。`model_calls.billing` 保存不可重新计价的调用快照，`model_prices` 保存当前人工价格及版本；统计接口增加按币种汇总、未知费用次数和四类分组。存在价格或费用记录时拒绝有损降级，需配套升级前备份及镜像回退。恢复历史备份可能回退普通账目，不将本地估算用作独立财务账本。

## 验证记录

- Windows 专项 34 项通过，1 项 PostgreSQL 行锁并发测试在 Windows 跳过；最终 Linux／PostgreSQL 全量回归 1,536 项通过（760.29 秒），包含同版本价格并发保存检查。
- 前端 262 项通过，类型、菜单／开场静态检查与生产构建通过。沿用午夜蓝、四字菜单和既有组件，没有新增 CSS 或顶部介绍区。
- 独立 PostgreSQL 迁移验证全新升级、空配置降级／再升级、ORM／SQL 字段一致及有价格时拒绝有损降级。
- Core／worker 重启后，全部实际合成调用与原有 CNY／USD 金额保持不变，没有新增调用或重新计价。
- 最终构建的浏览器 DOM 检查通过 375、768、1024、1440px 无横向溢出；375×540px 单价确认可操作，步骤切换后焦点留在弹窗内，Shift+Tab／Tab 循环及 Escape 返回设置按钮通过，未保存浏览器里的测试表单。费用归属切换显示实际汇总。截图接口持续超时，因此本次未生成截图，不能据此宣称像素级视觉复核完成；临时页已关闭、视口及原可见性已恢复。
- 真实 HTTP／独立 worker 使用本地合成服务，四次最终聊天验证原单价、改单价、切换币种和停用：已知估算分别为 CNY 28、USD 5，停用后未知。重复请求返回同一生成，不重复调用。
- 测试也记录实际辅助记忆抽取调用。初始夹具未返回抽取 JSON，触发现有有限重试，这些调用保留在统计中、费用未知；修正夹具后继续验证，没有删除或忽略它们。首次重启后的过早 HTTP 请求连接失败已保留日志，等待就绪后继续，未重新生成已有聊天。
- 未读取或复制正式账号的模型密钥，未调用真实付费提供商、登录 QQ 或发送真实消息。实际厂商用量格式、定价准确性和真实账单对照仍待验证。
