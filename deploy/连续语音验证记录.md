# 连续语音验证记录 · v1.37

验证日期：2026-10-30，Linux 容器／独立 PostgreSQL、Windows Python 3.13.15、Chromium 浏览器。协议服务、账号、转写文本和音源均为隔离测试数据，不访问真实付费模型、不采集物理麦克风、不登录或发送真实 QQ。

| 范围 | 已核验结果 |
|---|---|
| Linux＋独立 PostgreSQL 后端 | 完整 1,186 项通过，707.31 秒；随后移除与需求不符的固定回合上限，最终 Linux 镜像语音、人格音色、路由和恢复 159 项通过（105.69 秒），含连续语音 21 项 |
| Windows 相关后端 | 语音、连续语音、人格音色、路由与恢复 159 项通过 |
| 前端 | 全量 225 项通过；语音与采集 39 项，覆盖合成信号、静音、短噪声、25 秒丢弃、播放阈值、暂停、迟到权限、关闭、空闲计时、转写错误、自动播放限制、发送重试及打断回执 |
| 类型、框架与构建 | TypeScript、47 路由、四字菜单、十阶段动画及 CSS Token 静态检查通过；本地／Docker Web 构建通过，保留既有单包体积提示 |
| 真实 HTTP／独立 worker | 配置并验证合成 ASR／TTS，明确创建连续会话；自动转写排队、重复提交、拒绝同 ID 改写确认属性。重启 Core 后 worker 继续完成回复；不创建记忆抽取作业、候选或事实，后续回合固定未听完的播放边界，关闭会话后拒绝新输入 |
| 服务端约束 | 默认为 manual；自动输入只允许 continuous；不设固定聊天次数，超过 20 回合仍可交流；重投不重复计数，失败不计数。保留会话有效期和音频调用限流。未经核对输入绕过联系偏好命令，不接收工具／协作授权；抽取 worker 在模型前、写入前复查来源标记 |
| 记忆与恢复 | 手动确认仍沿原记忆流程；伪造／重投抽取 outbox 不调用模型；抽取期间来源变成未确认也不写入。恢复隔离关闭连续会话、撤销登录，不重新开麦 |
| 浏览器实际 AudioWorklet | 专用测试页用 Web Audio 合成波形，经产品同一 Microphone／1024 帧 worklet 分段，两次生成 16 kHz WAV；结束后合成轨道停止。未请求真实麦克风权限 |
| 浏览器产品闭环 | 仅测试页提供合成输入、静音输出，产品正常开启／停顿提交／标记未核对／完成核心回复／逐段播放／返回聆听；60 秒空闲自动关闭实际测试捕获。未向正式 Web 镜像复制测试入口 |
| 页面与键盘 | 375、768、1024、1440px 无横向溢出，1024×480 可滚动；连续模式默认关闭、开会话不自动开麦、结束保留文字、输入输出控件和按钮键盘顺序正常。刷新有效会话仍需点击身份确认 |
| 数据库 | 空库 `0032 → 0031 → 0032` 通过，新增列与 ORM 一致；含连续会话的库拒绝直接降级，仍保持 `0032` |

本地音量门限不是语音识别或说话人辨认，不能证明真实环境中可排除回声、风扇声或他人讲话。中文识别、真实设备与音色、P50／P95 延迟和 30 正常＋10 打断＋10 断线／修订专项仍待实测；原生双向 Realtime、字幕修订及主动语音尚未实现，不以这些隔离结果替代。

本机已保存升级前 `.preview/lingxi-pre-v137.dump`（173,133 字节）并核验 pg_restore 目录，保留 `lingxi-{core,worker,web}:pre-v137` 配套镜像。部署 schema 0032；17 类业务数量及模型／密钥密文／用途／人格／语音／路由全字段摘要未变，既有语音会话仍 manual／0，未导入合成配置。Core／worker 的 89 个源文件与合约摘要、OpenAPI、0032 列结构、worker 心跳和服务健康已核验；最终移除固定回合上限后的配套镜像已再次发布，全部上述数据／配置／源摘要／健康检查通过；正式入口 JS／CSS 字节与最终本地 dist 一致，Nginx 鉴权及请求体限制通过，正式镜像不存在合成测试页。备份含敏感数据，仅本机保留，不提交仓库。
