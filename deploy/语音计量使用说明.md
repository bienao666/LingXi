# 语音计量与单价管理（v1.72）

## 使用入口

在「数据日志 → 用量预算」查看语音用量，展开「语音单价」。先在语音配置选择识别、合成、实时转写或实时合成模型，再设置对应单价。单价默认未配置，不影响语音开关；读取和保存单价不会调用模型。

编辑后先预览，再勾选已核对供应商计费单位并保存。支持 CNY／USD，非负十进制单价，最多六位整数、六位小数。只有供应商确实免费时填写 0。配置、连接或单价版本变化会拒绝旧页面提交，需重新加载核对。

## 计量与估算边界

| 类型 | 本地计量 | 可配置的估算单位 |
|---|---|---|
| HTTP 识别 | 已发起请求的有效 WAV 帧数／采样率 | 每分钟输入音频 |
| 实时转写 | 实际成功转发的 24 kHz 单声道 PCM16 帧数 | 每分钟输入音频 |
| HTTP／实时合成 | 实际提交文本的 Unicode 码点数，含空白、标点；收到的有效音频时长 | 每百万输入字符 |

本功能只适用于供应商确实采用表内单位的服务。按 token、分档、最低收费、取整、固定请求费等计费的服务不能套用此单价，保持未知。这里是本地输入量估算，不是供应商账单，不换汇、不含插件服务费，也不是费用封顶。返回音频时长不等于用户已听到或播完的时长，网络耗时不能用于推算音频长度。

仅成功完成、已实际发起且有匹配单价和计量的调用估算费用。失败、取消或预算拒绝不推断免费；供应商仍可能收费。用量与费用分别统计，因此已计量的失败请求仍可能费用未知。旧调用不补算音频时长或重定价。

单价在发起请求前固定快照，修改只影响之后开始的调用。提供商版本变化后旧单价不再匹配，需重新核对。普通浏览器语音归属 voice，QQ 语音归属 qq，显式验证归属 validation；历史归属不改写。

## 数据与接口

- `GET /api/admin/audio-prices`：当前语音配置对应的单价槽位。
- `PUT /api/admin/audio-prices/{key}`：认证、CSRF、所有者／工作区和版本检查后的单价保存。
- `GET /api/admin/usage`：`audio` 返回次数、已计量／未知次数、输入／输出毫秒及输入字符数。
- 调用记录仅返回白名单计量和定价来源，不保存录音、转写正文或合成文本到计量字段。
- 迁移 `0057` 增加 `audio_prices`；存在单价时禁止直接降级删除表，使用配套备份和镜像整体恢复。

375／768／1024／1440px 页面和弹窗检查、预览焦点、Tab、未确认禁止保存及 Escape 焦点返回通过。测试使用隔离数据和本地协议，不调用真实付费模型、不申请麦克风权限、不登录 QQ；实际供应商计费、音频体验及完整产品验收仍待验证。
