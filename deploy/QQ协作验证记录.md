# QQ 后台协作验证记录

版本 v1.43，2026-10-31。服务器模式，迁移 `0037`。这是实现与验证记录；合成协议证据不能替代真实模型或真实 QQ 兼容验收。

## 本次实现

- 明确文字 `/协作 任务目标` 建立待确认请求；群聊仍须现有提及或命令触发。普通文本、引用、语音转写和绑定不授权执行。无需可用模型即可记录请求。
- Web「平台接入 → 渠道规则 → 后台协作」逐次选择助手、工具、记忆、共享子目录和预算；预览显示完整配置、原接收者、附件及费用说明。没有确认，不建协作 DAG、不调用协作模型、不执行工具。
- 预览五分钟有效，绑定登录、版本、配置摘要；确认丢包重试返回同一任务。请求及执行授权共 24 小时有效，变化或过期需要重新提交。
- 群聊禁止所有者个人记忆。允许个人记忆的本人私聊仍须本次勾选；无记忆绑定私聊和群聊使用隔离 actor。执行所有者与来源／附件所有者分别校验，不让群身份继承所有者权限。
- 只分享经审核的选定人格、角色和模型快照，相关版本变化阻断执行。共享目录只能是授权根内明确子目录，节点路径基于该子目录解析，不允许读取根目录／上级／符号链接，只列元数据。
- 持久化 DAG、并行、预算及 API／MCP 工具复用现有执行器。每次工具调用仍须 Web 所有者核对实际参数与费用，预览说明结果将返回的 QQ 受众；外部操作未知不重放。
- 待工具确认和最终汇总由主助手生成一次通知，经既有 OneBot 回执链返回原会话。私聊不转群、群结果不转私聊、不换渠道、不播音。通知超出一小时投递窗口取消待发部分，结果保留在 Web，不补发过期内容。协议接受不等于已读。
- 来源、附件、记忆、身份和渠道变化传播至在途任务及待发结果；迟到模型结果不能重新发布。恢复备份隔离全部旧 QQ 任务授权与通知；存在记录时禁止直接降级丢弃屏障。

## 自动化和独立服务证据

新增 `backend/tests/test_channel_tasks.py`，覆盖明确命令、无模型待确认、重复消息、私群隔离、逐次授权、预览变化／过期／登录变化、共享子目录、附件主体、API／MCP 确认、来源／角色／渠道撤销、删除后不回传、未知结果不重发、离线过期与恢复隔离。

新增前端请求授权交互测试，并回归渠道与工具界面。检查未勾选确认不能执行、完整配置展示、版本冲突保留草稿、预览编辑使用新版本、拒绝确认、实际回执措辞及详情链接。类型、菜单、十阶段动画和构建检查沿用现有脚本。

最终并发修复后，在 Linux／PostgreSQL 上运行 QQ 协作、渠道、子助手、附件、远程工具和备份相关回归，**204 项通过**。新增双请求屏障测试：同版本并发预览只有一个成功，另一个返回 409；并发确认都返回同一执行 ID，只入队一次。加锁后显式刷新 ORM 对象，避免等待锁时沿用旧版本。

Linux／PostgreSQL 完整后端回归 **1,427 项通过**，用时 884.03 秒。该完整构建包含目录回调与通知过期修复；随后最终锁刷新改动及新增两个并发场景以以上 204 项相关回归验证。两轮均通过，不把不同构建的执行数量相加为同一轮全量测试。仅保留已有 Starlette/httpx 弃用提示。

前端全量 **248 项通过**；类型、47 条路由、十阶段开场与生产构建通过。最终测试 Core／worker 的 106 个源码、迁移、OpenAPI 与辅助文件摘要一致，迁移为 `0037`，动态 OpenAPI 与仓库一致。相关记录为 `.preview/qqtask-affected-final.log`、`.preview/qqtask-frontend-full.log` 及镜像构建日志。

独立容器使用新的测试数据库、测试身份和仅合成模型端点；没有复制正式凭据或导入测试数据到正式环境。通过真实 HTTP 与认证反向 WebSocket 接入，而非直接调用网关内部函数：

1. 重复 QQ 请求只记录一次；Web 预览前及确认前，模型调用均为零。
2. 确认只建立一个排队任务；Core 重启后由独立 worker 恢复。
3. 两个合成分析节点与一次汇总完成，只向原群投递一次；保存真实协议接受回执，重连无自动重发。
4. 执行中撤销后，迟到模型响应被丢弃，没有新节点结果或 QQ 通知。

记录：`.preview/qqtask-http.log`、`.preview/qqtask-postgres-final.log`、`.preview/qqtask-frontend-full.log`。旧的初轮日志保留用于定位，不作为最终通过证据。Linux 独有的共享目录检查曾漏传回调，已修复并在最终镜像重新验证。
