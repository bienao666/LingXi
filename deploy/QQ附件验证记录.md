# QQ 图片与直链文档验证记录

版本：v1.33；日期：2026-10-30；数据库迁移：`0028`。

本批交付 QQ 图片／直链文档接收及文字问答代码。使用独立测试账号、合成 OneBot 对端和模型协议服务，未登录真实 QQ、未向联系人发送消息，也未调用付费模型。真实 NapCat 上报字段、CDN 域名、链接时效和模型质量仍待验证。

## 实现范围

- 渠道规则默认关闭附件接收，预览后保存开关和精确公共 HTTPS 域名；私聊绑定、群白名单与触发、去重及限流先于附件留存。
- `image.data.url` 和 `file.data.url`／`name` 进入持久化接收。文件 ID、本机路径、原始 CQ 字符串、语音、视频和文件上传通知不被当成文件内容。
- 下载复用系统代理、DNS 校验与固定目标 IP，禁止重定向和压缩传输；不携带 QQ 令牌、Cookie 或模型密钥。临时签名 URL 加密存储，五分钟接收有效窗口，成功／失败／取消后清除。
- 最多 10 个附件、单个 20 MiB、合计 50 MiB、下载总时限 120 秒。解析、图片归一化和视觉验证复用统一 MediaService；整个消息全部可用后才提交聊天。
- 附件固定原会话，原会话删除后不转移到新会话；仅附件消息的默认指令不抽取为用户事实。群聊及非共享私聊使用独立主体。
- 删除和撤权影响在途及未投递结果，QQ 真正发送前再次检查来源；已接受回执如实保留。恢复隔离取消旧接收并清除临时 URL。已有接收记录时禁止直接降级丢弃来源屏障。
- 管理页仅展示附件类型、大小、进度和脱敏错误，不暴露签名 URL、文件名或模型上下文。QQ 本批只输出文字。

## 实际网络与容器

独立 Compose 项目 `lingxi-channel-media-qa` 使用独立 PostgreSQL、运行卷和测试身份。TLS 原点、CONNECT 代理及 OneBot／模型对端均为隔离测试服务；测试 CA 仅挂载到 QA 容器，不修改正式镜像信任库。

通过实际 HTTP 登录／配置与认证反向 WebSocket，先持久化图片和文档接收，重启 Core 后再启动 worker。实际 HTTPS 请求经已配置代理携带签名查询参数到测试原点，统一解析后同一模型输入含归一化图片与文档证据，模型输入不含下载 URL。核对协议接受回执、原会话、消息 ID 去重、不重复下载、不跟随重定向及删除后结果失效。

迁移空库往返、含记录禁止降级、源文件哈希、Core／商店 OpenAPI 和新增表列／索引均在发布前核对。浏览器检查 375、768、1024、1440px，以及 375×480／768×480 矮屏、表单滚动、范围预览、Tab 循环、Escape、焦点恢复和记录页面。

正式 Core／数据库／Hindsight 健康，worker 心跳在线；发布静态资源与本地最终构建一致。88 个源文件／合约哈希、OpenAPI、数据库列／索引、未登录 API 保护和 Nginx 请求限制核验通过。测试证书、QA 代理、测试身份及配置未进入正式部署。
