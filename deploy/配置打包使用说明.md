# 配置打包使用说明

版本：v1.78；数据库：沿用 schema0059。入口为「系统设置 → 系统配置 → 配置打包」。

## 覆盖范围

| 模块 | 配置值 | 生效范围 |
|---|---|---|
| 空间默认 | 名称、IANA 时区、默认人格引用、历史字节预算 | 沿用基础配置规则；新回合固定版本，已有提醒不改时间 |
| 媒体限制 | 附件数、单个／合计大小、允许类型 | 新上传、选择、协作与 QQ 接收；不删除旧文件或取消已提交模型任务 |
| 运维偏好 | 结构化运行日志保留天数、每日 token 告警 | 后续清理及告警；缩短保留期可能永久删除过期日志 |
| 调用限额 | UTC 日请求尝试次数、单次执行请求尝试次数 | 沿用模型请求准入；不清空计数，不撤回已发送请求，不是金额上限 |

使用现有午夜蓝组件、四字菜单和原系统配置页，不增加路由或恢复顶部介绍区。原「导出配置／导入配置」仍只管理四项空间默认，旧文件格式继续可用。「导出整包／导入整包」使用独立格式，包含上述四个模块。

配置包不包含模型连接及密钥、代理、人格正文、插件安装、账号凭据、服务器资源授权、联系许可、聊天、附件或记忆。它不能代替备份、迁移或凭据重新授权；更广泛的跨模块配置版本与回退仍是产品目标。

## 操作流程

1. 点击「导出整包」，保存 `lingxi-configuration-bundle.json`。
2. 在目标系统点击「导入整包」，选择不超过 64 KiB 的 JSON 文件或粘贴内容。
3. 选择导入范围。包内未提供的模块不能选择，未选择模块保持原值。每个所选模块必须包含完整字段，未知字段及 `null` 模块被拒绝，不能用缺省字段悄悄重置已有值。
4. 点击「预览整包」。服务器重新检查当前版本、字段约束和默认人格引用，逐项展示旧值、新值及实际模块版本；无变化时不生成预览。
5. 核对差异、日志清理和请求限额的影响，勾选确认后点击「确认整包」。预览五分钟有效，绑定当前账号、工作空间及登录会话；浏览器只提交预览凭据。
6. 成功后刷新空间名称、基础配置、配置历史及模块版本，焦点回到主内容。取消返回原按钮，预览与错误出现时焦点进入相应内容；弹窗支持 Tab／Shift+Tab 循环和矮屏滚动。

默认人格只保留引用，不按同名猜测或重建。换服务器后引用不存在、停用、版本变化或不属于当前账号时，须重新选择有效引用，或在包中明确使用 `default_persona_id: null` 指向内置并肩伙伴。

## 冲突、恢复与原子性

所选模块的任何版本变化都会使整包确认失败，即使该模块在预览中没有字段差异；取消选择的模块不参与此包版本检查。修改默认人格的内容也会使预览失效。页面保留草稿与错误，须返回修改、刷新版本并重新预览，不自动重试或覆盖。

所有配置及各模块审计在一个数据库事务中提交。最后一个模块发生冲突时，前面的更改与修订一并回滚。预算模块使用自身行锁，与普通模型准入及单模块限额修改串行化；并发确认至多应用一次，重复确认返回 409，不再增加版本。

保留导出的旧配置文件，可以重新导入以恢复配置值；各模块版本继续递增，已计模型请求次数保留。已清理的日志、已发送的请求以及其他外部动作不能通过恢复配置值撤销。空间默认仍写入既有配置历史；此批不新增覆盖其他模块的统一历史表。

## HTTP 合约

| 方法与地址 | 行为 |
|---|---|
| `GET /api/admin/configuration-bundles` | 当前完整配置文档及四个模块版本 |
| `GET /api/admin/configuration-bundles/export` | 只导出配置文档，不包含源系统版本或身份 |
| `POST /api/admin/configuration-bundles/previews` | `{document, versions}`，版本键必须与选择的模块严格对应 |
| `PUT /api/admin/configuration-bundles` | `{token, acknowledgement: "atomic_configuration_changes"}`，单事务确认 |

文档格式为 `lingxi-configuration-bundle/v1`，模块键是 `workspace`、`media`、`operations`、`model_budget`。可使用只含一个完整模块的文档，例如：

```json
{
  "format": "lingxi-configuration-bundle/v1",
  "modules": {
    "operations": {
      "log_retention_days": 90,
      "daily_token_alert": 0
    }
  }
}
```

接口复用登录、CSRF／Origin 和服务端工作空间边界，不接受浏览器自报身份或授权。预览不是执行授权；未知模块、格式、额外权限、缺失字段或不匹配版本均拒绝。确认在获取所有者行锁后再次检查会话及工作空间。
