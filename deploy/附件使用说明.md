# 附件使用说明

当前实现覆盖 Web 文档与静态图片。QQ、子助手、语音消息、OCR、视频和图像生成尚未接入附件链。真实提供商的理解质量需另行验收。

## 在聊天中使用

1. 先配置并验证日常对话模型。在聊天输入区点击“上传附件”，或“选择文件”选择当前工作空间已有附件。
2. 等待“可用附件”。点击文件名称可查看原文位置、解析范围或图片；失败附件会显示实际原因。
3. 输入文字问题后发送。文件和消息由服务器持久化，关闭浏览器不取消已提交生成或解析。
4. 在回答中核对来源；模型收到附件 ID、文件名和行／段／页／工作表／单元格位置。模型生成的引用不天然等于事实正确，需按原件核验。

附件不能重复选择。单条消息最多 10 个，单个 20 MiB、合计 50 MiB；平台与模型的实际限制可能更低。发送前不允许存在解析中、失败或已删除附件。超出上下文预算时要求拆分，不能通过删除输入的一部分后声称完整阅读。

上传失败可点击“重试上传”，沿用同一请求编号。成功上传的文件保留，后续未发送的文件需重新选择。输入区“移除”仅移出草稿，不删除服务器文件；删除请到“文件管理”。

## 图片与模型验证

在“模型管理 → 模型目录”先通过对话验证，再点击“验证视觉”。探针生成两行三列随机色块，要求模型识别完整顺序，实际请求经已配置的服务器代理和提供商凭据发送；会产生一次普通模型调用，费用缺少单价时未知。界面只在完整匹配后显示“图片探针通过”，连接版本变化后需要重新验证。

这只验证一次图片输入链路，不代表全面视觉能力、准确率、中文质量或其他模型协议通过。文字模型无法处理图片时明确失败；切换模型后不会静默删除历史图片。可重新验证或新建纯文字会话。

仅支持静态 PNG、JPEG、WebP，最多 1600 万像素。服务器解码并校正 EXIF 方向、移除元数据，转换为 JPEG 后发送和预览；原件仍单独保存供下载，不缩小像素尺寸。规范化图片的原始数据另有单条 12 MiB、整段历史 24 MiB 的传输预算，超过时要求压缩或减少数量。透明图片会转为 RGB，精确透明度不参与首批理解。

## 文档解析范围

| 格式 | 来源位置与范围 |
|---|---|
| TXT、Markdown | UTF-8／GB18030 文本，保留行号，不执行 HTML 或链接 |
| CSV | 保留原始行号和字段值，不执行公式 |
| PDF | 每页提取文字并保留页码；加密、超过 300 页或任何无文字页会失败，专门 OCR 尚未实现 |
| DOCX | 提取正文段落及表格中的段落，保留段号；不加载外部关系，不解释页眉页脚、图片或完整版式 |
| XLSX | 按工作表和单元格位置提取原始值；不解释样式和日期序列，不执行或信任公式及缓存；有公式须先转换为值 |

解析总预算最多 16 万字、5000 段，压缩展开最多 32 MiB；Linux 中使用离线子进程，内存限制 384 MiB、CPU 20 秒，父进程最长等待 35 秒。无法安全完成会显示失败，不返回伪造内容。语义搜索长文、智能分块补读和自动孤立文件回收仍待完善。

## 文件管理与删除

“数据日志 → 文件管理”支持搜索、游标分页、查看来源和下载原件。内容下载要求有效登录，不接受任意服务器或用户电脑路径，不提供公共静态文件地址。原件以附件下载，预览只用服务器生成的 JPEG 或转义后的解析文字。

删除前展示确认。确认后立即停止检索和生成使用，清空解析数据、作废相关回答及后续衍生回复，独立删除记录可在恢复时重放；后台清理原件、规范化图片和解析临时文件。清理最终失败显示实际状态，可点击“重试清理”，不会因此重新开放附件。删除无法撤销，也无法收回已经下载、显示或提交给模型的内容。

删除会话时，未被其他有效会话共用的附件一并删除；共用文件保留。直接删除文件会影响全部引用它的会话。附件本身不会自动产生个人长期事实，上传内容、临时解析和长期记忆分别管理。

## 部署与恢复

迁移 `0009` 新增 `media`、`media_links` 和 `model_vision` 表。Core 和 worker 必须挂载同一持久卷到 `LINGXI_RUNTIME_DIR`，默认 Compose 使用 `deletion-ledger:/app/runtime`，附件在其中的 `media/`。不要只给某个进程挂载本机临时目录。

Nginx 单请求上限 20 MiB，Core 按流再次检查；一次仅上传一个文件，多文件顺序上传。Core 和 worker 镜像使用固定依赖 Pillow、pypdf、defusedxml，不需要额外系统解析服务或新的基础镜像。

备份必须同时考虑数据库、附件持久卷和独立删除记录。数据库 dump 不包含原件；恢复旧数据库后先重放保留的删除记录，再允许服务读取资料。禁止用旧删除记录覆盖新记录。文件存储和数据库不是同一事务，上传中断可能留下无业务记录的文件，接口无法读取，自动回收与容量告警待运维模块补全。

## 当前验证边界

完整 Linux／PostgreSQL 回归、解析器和浏览器协议服务只证明权限、持久化、解析、协议和失效链路。真实模型的图片理解、文档推理、附件准确引用，以及与 QQ、子助手和实时语音联合使用仍需独立验收。
