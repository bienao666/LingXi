# QQ 语音回复验证记录

版本：v1.35；日期：2026-10-30；数据库迁移：`0030`。

## 实现与边界

已实现独立默认关闭的语音回复开关、保存前范围预览、短回复 TTS、加密临时波形、文字／语音独立投递回执与真实合成阶段展示。正常触发回复的完整文字保留；600 字以内可附一条 0.1–60 秒、6 MiB 的语音，超长／失败仅保留文字并说明原因。不为主动消息开启语音，不创建浏览器播放会话。

付费调用前提交 `calling` 屏障；调用中断、租约接管不重放未知合成。服务、语音配置、人格音色及原始回答固定版本，合成前、完成后、发送意图前检查身份、消息、会话、记忆和附件来源。发送意图持久化后再发 WebSocket；断线不自动重发，不把协议接受写成送达、已听或已读。

波形只短期加密存储，发送意图、来源失效、权限变更、人工结束等待、恢复隔离与一小时到期时清理；离线也由 worker 每 30 秒检查过期。恢复检查点只携带无正文、无波形的语音调用／投递记录和原外部消息 ID，旧备份缺少这些记录时仍可保留去重屏障。凭据为空且符合服务器 QQ 隔离身份格式的 actor 不再被误判为额外登录所有者；真实第二个所有者仍拒绝单所有者恢复。

## 验证结果

- Linux／独立 PostgreSQL 完整后端 **1105 项通过**（恢复保护最终补充前的全量结果，693.51 秒）。补充较旧备份恢复与 QQ 隔离身份检查后，最终镜像的语音回复、平台、语音／人格及备份相关回归 **147 项通过**（79.76 秒）。没有把前一次全量结果冒充最终新增代码的完整重跑。
- Windows 最终语音回复＋备份专项 **57 项通过**，其中新增语音回复 **32 个场景**：默认关闭、私聊／群聊、完整文字与单语音、未验证及配置变更、超限、限流、坏波形、超时、在途来源失效、付费调用恢复、租约丢失、未知发送、拒绝假回执、离线到期、人工结束、身份撤销及旧备份恢复去重。
- 前端 **194 项通过**；类型、47 路由、四字菜单、10 阶段动画与 CSS Token 静态检查通过；本地和 Docker Web 构建通过。主 JavaScript 约 662 kB，现有分包建议仍存在，不是构建失败。
- 隔离真实 HTTP 服务验证模型与 TTS 配置；经认证反向 WebSocket 接收文字，持久化 chat 作业后重启 Core，再启动独立 worker。完整文字后单独投递超过 64 KiB 的 WAV base64；文字／语音分别以真实协议形状回执确认，重复原消息 ID 没有再次生成或合成。
- 最终镜像再次完成 HTTP／WS／worker／重启及去重验证。测试服务模拟供应商，不能作为真实供应商或 QQ 账号接入证明。
- 空库 `0030 → 0029 → 0030` 通过；已有语音回复记录时拒绝直接降级，schema 保持 `0030`。Core／商店 OpenAPI、新增列与索引，以及 **61 个运行时源码／合约哈希**与 QA、正式 Core／worker 一致。
- 浏览器验证 375／768／1024／1440px 及 375×480 矮屏，无横向溢出；预览／继续编辑、Tab／Shift+Tab 循环、Escape 关闭及焦点返回正常。最终收发记录显示文字和语音分别被协议接受，不暴露正文、转写或波形；最终页面无浏览器错误日志。
