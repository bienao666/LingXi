## 全量和部署

2026-10-31，本机正式 Docker 已升级至 `0046`。升级前确认没有运行中的作业、活跃聊天与语音会话，保存升级前镜像及数据库备份，并检查备份目录可读。

- Core 与 worker 各自核对 117 项源码／迁移／OpenAPI 摘要，实际 schema 与媒体接口一致。
- 升级前后 30 类业务数据计数及配置、调用记录、附件摘要一致；原媒体策略保留，未导入合成账号或测试授权。
- 正式 Web 的 15 个文件与生产构建逐字节一致；未登录读取媒体策略和提交预览均返回 401。
- Core、PostgreSQL、Hindsight 健康，worker 有有效心跳；旧心跳窗口到期后实际在线计数为 1。

独立 `lingxi-media-types-qa` 容器、网络和三个测试卷已清理；按项目标签核对无残留容器或卷。正式数据卷及升级前备份保留。

部署入口为 `http://127.0.0.1:8080/#/settings/media`。服务器专项与界面验证不代替真实 QQ、实际模型、中文记忆质量或物理音频验收；系统迁移向导等剩余范围继续待开发。
