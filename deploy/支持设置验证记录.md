# 聊天支持设置验证记录 · v1.42

本轮补齐明确聊天指令修改持久支持偏好，并修复旧页面保存时可能重新激活已过期自述的问题。只使用独立测试库、合成账号与协议模型，不将其作为真实中文理解质量验收。

## 入口与语义

在独立 Web 文字对话单独发送下列完整指令；支持尾部中文句号、感叹号和逗号及首尾空白。其他标点、引用、转述、假设与复合句按普通对话处理，不修改设置。

| 指令 | 结果 |
|---|---|
| 以后先听我说 | 保存倾听模式，影响后续对话 |
| 以后多给建议 | 保存建议模式 |
| 以后优先帮我行动 | 保存直接协助模式；仍需独立任务授权 |
| 恢复平衡回应 | 保存自然平衡模式 |
| 关闭自动情绪线索 | 关闭自动观察、清理旧线索，保留有效手填自述 |
| 关闭情绪适配 | 关闭适配和自动观察、清空手填自述及旧线索 |
| 清空当前感受 | 清空手填自述及旧线索，自动观察开关不变 |

明确指令由服务端处理，不调用模型、不创建任务、不抽取记忆。联系人设置与支持设置分开，不把“直接告诉我结果”等联系偏好改成情绪设置。没有有效模型时也可停止观察或清空感受；只有新开启自动分析才要求当前验证过的抽取模型。普通聊天不能凭模型回答宣称已经修改设置。

QQ、Web 中的 QQ 历史、附件消息、确认或未确认的语音、编辑分支不会执行支持指令。自动观察只能在设置页明确开启，本批不提供开启付费分析的聊天指令。原始指令和真实回执进入统一历史；操作记录不包含感受正文。删除来源聊天不会撤销已经完成的设置，重新生成不会重做设置。重复请求不会覆盖更新后的偏好；版本冲突返回 409。

## 自述有效期

保存逻辑与聊天指令复用同一服务、所有者锁、版本检查和恢复屏障。比较规范化后的持久原文，避免旧表单携带相同文本、不同空格或新时长时延长有效期。已过期且没有明确续期的内容清空。新文字重新计时；同样的文字如需继续，勾选“重新确认当前感受”并保存。该勾选不会立即请求，也不会在成功保存后继续保留。

`PUT /api/support-preferences` 新增请求字段 `renew_report: false`，版本、非空感受及允许适配检查继续生效；不持久保存确认标志。原响应保持 `SupportView`，GET 不产生续期。支持设置变化仍会清理旧短期线索、撤销相关在途输出及已有衍生回答；独立删除记录保证恢复旧偏好时先清理失效内容。

## 范围边界

本批未实现任意自然语言设置解析、语音情绪识别、QQ 任务授权或群聊子助手协作。QQ 的记忆共享授权不能替代执行授权；群聊还需独立的受众范围及角色数据隔离。真实模型质量、记忆 150 题及真实 QQ 兼容继续待验证。本批没有新迁移，仍使用 `0036`；回退需配套镜像、备份和最新删除／撤销记录。
