# 会话内主动语音验证记录

适用版本：v1.49；数据库迁移：`0043`。本轮为有来源的 Web 主动交流增加会话级播音许可，使用现有 ASR → Core → TTS 链路，不代表原生实时语音或真实自然交流质量已验收。

## 使用与边界

- 在对话窗口明确勾选“主动开口”，开启语音；默认关闭，授权仅限本次语音会话。开启不打开麦克风，连续聆听仍须独立操作。
- 仅对新产生且目标匹配的 Web 联系建立候选，最多等待 120 秒，实际期限还受话题和语音会话约束。浏览器空闲至少三秒，且没有输入、录音、转写、生成、待确认草稿或其他播报时才领取一次。
- 沉默不创建话题，已有站内联系、过期、已领取、开关关闭前和旧会话的候选不补播。QQ 目标不改投声音，多个浏览器不各自领取同一联系。
- 会话内不设置普通会话外每日次数和间隔；仍检查联系偏好、安静时段、暂停、允许的话题、拒绝来源和权限。语音联系不消耗普通会话外额度，后续普通 Web／QQ 联系继续使用自己的额度。
- 起声先本地停播。关闭、结束、隐藏、离线、拒绝、记忆纠正／删除或配置变化后不继续播放失效内容；合成返回、输出设备切换、领取与手动恢复的迟到响应不能重开声音。播放期间每秒核对来源和授权，每段合成前后及手动继续前重新核对；已经播放或发给上游的内容无法撤回。
- 完整播完并收到回执的短句进入下一轮语音上下文，半句和未确认内容不计。Web 保留完整文字；“主动交流 → 联系记录”显示语音状态和确认段数，不能据此声称实际听见。
- 连续模式精确识别“先别聊”时暂停聆听并关闭本次主动开口，不修改长期联系偏好。其他长期拒绝通过明确文字指令或联系偏好生效。
- 每次合成复用现有音色验证、人格快照及每分钟共享音频预算；失败不自动重试付费调用。服务器连接失败结束语音，文字和后台任务保留。

## 合约与状态

| 接口 | 用途 |
| --- | --- |
| `POST /api/voice/sessions` | 输入 `allow_proactive`，默认 false；固定用户、登录、工作区和目标对话 |
| `PUT /api/voice/sessions/{identity}/proactive` | 更新本次许可；切换前使旧候选失效 |
| `POST /api/voice/sessions/{identity}/proactive-playback` | 输入 `idle_ms`；核验自然间隔后原子领取一次，可能返回空播放计划 |
| `GET /api/voice/playbacks/{identity}` | 核验有效会话、来源和偏好，返回真实播放状态 |
| 原有音频／进度接口 | 每段合成和回执，复用权限、验证与顺序检查 |

`voice_contacts` 关联联系、消息、会话、播放计划、偏好版本、有效期和音色快照。候选状态为 candidate、claimed、expired、invalidated、failed，播放终态为 completed 或 stopped；界面以播放回执为准展示确认段数。模型不授予授权，浏览器报告的空闲只是时机信号。

## 发布与恢复

升级前确认没有运行中的用户任务、生成或语音会话，保存数据库归档及配套 Core／worker／Web 旧镜像。迁移只增加默认关闭的许可字段和候选关联表，不修改现有语音配置、不创建或授予真实用户新许可。

恢复备份沿用删除／撤销重放和恢复隔离：关闭旧语音会话、注销旧登录、使旧语音候选失效，不自动恢复播音。使用本功能后不要只回退旧 Core；存在授权或回执时迁移明确拒绝降级，需要升级前配套归档和镜像，不能手工删掉回执强行回退。

日志与合成脚本保存在本机 `.preview/proactive-voice-*`、`.preview/proactive_voice_*`，含本机备份或测试凭据的内容不提交仓库。真实供应商、物理设备、自然程度、中文质量和延迟目标继续单独验收。
