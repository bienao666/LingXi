# 插件事件订阅验证记录

版本：v1.28。日期：2026-10-30（Asia/Shanghai）。本记录说明本批实际验证范围，不代表全产品验收完成。

## 实现范围

审核签名后的声明式事件包可经安装预览确认安装，再单独授权事件类型、签名密钥和接收额度。固定 HMAC-SHA256 Webhook 校验原始正文、时间、来源、事件类型、有效期和预算；重复事件只返回已有回执，改变同一标识正文会被拒绝。

外部事件为未独立核验的报告，经核心创建话题并遵守统一联系规则，不直接操作工具、读取记忆或发送通知。同一订阅的后续事件继承来源拒绝。删除、到期、插件与依赖变更、撤权及商店信任撤销会使相应来源和衍生内容失效。

## 隔离端到端验证

使用独立 Compose 项目、数据库、运行卷、商店与合成账号，经真实 HTTP 和 worker 执行；未调用付费模型、真实业务来源或 QQ。

1. 发布者提交事件包，由独立审核员审核签名，同步到 Core 后预览确认安装。
2. 单独保存订阅授权，签名事件实际接收，重复标识不重复创建话题；关闭联系时无站内消息。
3. 开启联系后，worker 根据来源生成明确注明“尚未独立核验”的站内消息，可接续会话。
4. 明确拒绝来源后，同一订阅后续事件仍被屏蔽，没有绕过拒绝再次联系。
5. Core、worker、商店重启后订阅、签名版本、去重及拒绝设置保留；最终镜像再次核对状态。
6. 删除事件清理正文并使衍生联系失效；撤销订阅移除密钥，新事件返回 401。
7. 重新授权后可接收新事件；页面密钥保持空白，确认未勾选时不能提交。

签名与请求边界、预算、并发去重、跨工作区拒绝、到期、依赖变更、签名撤销以及旧备份隔离等由自动测试补充覆盖。旧备份屏障属于测试验证，本批没有对正式数据库执行恢复。

## 页面与本机发布

375、768、1024、1440px 无横向溢出；375×540 矮屏弹窗可滚动，Tab 可到达授权控件，Escape 关闭后焦点回到编辑按钮。沿用既有账号授权页面，无新增菜单或顶部介绍区。

本机正式入口为 `http://localhost:8080`。确认无运行中任务和有效语音会话后创建 PostgreSQL 备份并核验目录，保留升级前镜像，升级至 `0023`。原业务数量及模型／策略／人格／语音配置完整字段摘要一致；Core、PostgreSQL、Hindsight healthy，worker 在线。正式工作区没有导入合成订阅、事件、连接、商店信任根或商店版本。

同源 Nginx 配置检查通过；未登录管理接口与伪造回调返回 401，超过 12 KiB 的回调返回 413。测试环境验证完成后移除独立容器与卷，保留脚本及截图。
