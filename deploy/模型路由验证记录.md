# 模型路由验证记录（v1.36）

日期：2026-10-30。实现普通聊天最终回答的显式自动选模及受控降级；真实供应商质量、地域证明、费用／延迟优化及其他用途路由不在本批验收内。

## 已执行验证

| 环境 | 结果与边界 |
|---|---|
| Linux／独立 PostgreSQL 全量后端 | 1,164 项通过，732.34 秒；随后只增加一项不重复派发／压缩的测试，最终镜像路由专项 51 项通过 |
| Windows 相关后端 | 聊天、任务、分支、上下文、QQ 语音及路由 185 项通过、1 项平台相关跳过；最终路由 51 项通过 |
| 前端 | 199 项通过；类型检查、47 路由、四字菜单、十阶段动画与 CSS Token 静态检查通过；本地和 Docker Web 构建通过 |
| HTTP／真实 TCP／独立 worker | 通过 HTTP 创建和验证两个隔离服务，预览后确认授权；消息排队后重启 Core，再启动独立 worker。首选返回 503，备用完成，仅一条回答、两次最终模型请求；重复提交不重放 |
| 运行追踪 | 实际模型、两个调用结果及 SSE `model_route`、`done` 事件通过；OpenAI→Anthropic／Gemini 降级协议夹具通过 |
| 数据与权限 | 预览 HMAC／过期／版本／地址／代理变化、跨工作区、模型用途、跨连接单独授权、QQ 所有者与发言主体隔离通过 |
| 恢复与失效 | 部分文字不续写；401 等鉴权错误不降级；最多两个最终调用；取消、记忆删除、提供商变化、路由变化、失去租约均不向备用继续发资料；运行中重领不重放 |
| 模态与预算 | 历史图片视觉验证、配置的上下文过滤、备用上下文不得更小、人格模型和任务预算保持固定通过；不代表供应商上下文容量已实测 |
| 页面 | 375／768／1024／1440 和 1024×480 无横向溢出；预览／取消、Tab 焦点、刷新有效身份确认通过。修复目录晚加载时固定模型下拉显示未选择的问题 |
| 数据库 | 空库 `0031→0030→0031` 通过；已有授权禁止直接降级，权威记录保持在 0031 |
| 本机部署 | 升级前备份和目录核验通过，保留 `pre-v136` 三类镜像；升级到 0031，16 类原业务数量和模型／密钥密文／策略／人格／语音配置摘要不变 |
| 发布一致性 | Core／worker 的 88 个运行源文件和合约摘要、OpenAPI、0031 列结构、服务健康与 worker 心跳通过；正式入口 JS／CSS 字节与本地 dist 一致，路由查询／预览／写入均需认证 |

正式环境路由授权表保持为空，即默认关闭，没有导入合成服务、测试账号或候选授权。未调用真实付费模型、未登录 QQ、未发送真实消息。隔离测试不能替代真实供应商授权、质量、限额、音质或 150 题中文记忆评测。
