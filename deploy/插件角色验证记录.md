# 插件角色验证记录

版本：v1.29。日期：2026-10-30（Asia/Shanghai）。本记录区分代码、隔离协议验证和真实供应商质量，不代表全产品验收完成。

## 实现范围

经审核签名的插件可声明 agent 模板，在“助手管理 → 助手配置 → 插件角色”单独选择本地人格、已验证对话模型、候选工具和相关记忆类别。安装不自动启用，相关记忆默认不共享，具体任务仍需明确授权。

角色进入既有统一调度器，参与任务中心和 Web 文字聊天的助手协作；沿用三并发、八节点、一层委派和主助手统一汇总。插件不携带模型凭据，不执行脚本、外部写入或自行通知，也不能直接写入记忆。

任务固定模板、插件、绑定、人格与模型版本。兼容更新保留旧任务版本，新派发需重新核对角色；撤销、缩小范围、依赖停用和信任变化阻止后续执行及迟到结果提交。撤销代际使重新启用不能恢复旧任务。

## 隔离端到端验证

使用独立 Compose 项目、数据库、运行卷、商店和合成账号，通过实际 HTTP、worker 与合成模型协议执行；不调用付费供应商、真实 QQ 或正式工作区模型。

1. 发布者提交角色包，独立审核员审核签名；Core 同步、预览确认安装后，尚不能直接调度角色。
2. 明确配置本地人格、模型、工具与类别并确认后，角色加入候选注册表；实际 worker 完成角色调用并由主助手输出一次汇总。
3. 暂停 worker 后排队旧任务，更新插件；重新确认前新派发不可用，旧任务仍固定旧模板。
4. 恢复 worker 后，旧任务使用 1.0.0，新任务使用重新确认的 1.1.0；配置、模板与摘要可追溯。
5. 规划期间撤销再启用角色，撤销前任务失败，不发布迟到内容；不能通过再次启用复活旧授权。
6. Core、worker、商店重新构建并重启后，绑定版本、可用性与配置保留；最终镜像再次完成一次实际角色协作。

自动测试另覆盖范围过滤、所有者／工作区隔离、模板与依赖摘要、记忆授权、来源失效、生命周期、恢复屏障及并发修改。恢复屏障为测试验证，本批没有对正式库执行恢复。

## 页面与本机发布

375、768、1024、1440px 无横向溢出；375×540 矮屏配置弹窗可滚动，Tab／Shift+Tab 可到达选择控件，Escape 关闭后焦点回到编辑角色。角色“助手协作”链接进入任务列表的协作模式。沿用既有午夜蓝主题、四字菜单和页面框架。

本机正式入口 `http://localhost:8080` 已升级至 `0024`。升级前确认没有活动任务和有效语音会话，保存并核验 PostgreSQL 备份，保留 `pre-v129` Core／worker／Web 镜像。原 16 类业务记录数量及模型、连接、用途策略、人格和语音配置完整字段摘要一致；Core、数据库、Hindsight healthy，worker 在线。

正式工作区未导入测试商店、信任根、版本、连接、事件或角色绑定。同源 Nginx 配置检查通过；未登录角色管理及伪造事件回调返回 401，超限回调返回 413。隔离环境验证结束后移除专属容器、卷和临时账号配置，保留测试脚本与截图。
