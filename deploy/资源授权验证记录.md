测试使用独立数据库、卷、随机密钥和合成账号。目录文件是测试夹具；没有复制正式对话、记忆、账号密钥或用户文件。

范围按完整路径段匹配；`projects` 不允许父目录、`projects-old` 或绝对路径。权限取部署、当前资源版本、第一方插件、角色及本次任务范围的交集。未经确认不产生授权；旧版本任务不会因扩大范围或再次授权恢复。已确认长期记忆保留，但失效资源来源阻止召回及后续回答；用户独立纠正可建立新来源。

## 全量与本机交付

2026-10-31 已完成本机正式 Docker 升级，入口为 `http://127.0.0.1:8080`；“系统设置 → 资源授权”可用。数据库迁移为 `0045`，Core 与 worker 的 116 项业务源码、迁移及 OpenAPI 摘要一致，接口契约与生成文件一致。

升级前停写并保存数据库备份 `.preview/lingxi-pre-v151.dump`，备份目录可读取；旧镜像保留为 `lingxi-core:pre-v151`、`lingxi-worker:pre-v151`、`lingxi-web:pre-v151`。备份含私有数据，仅存本机忽略目录，不进入 Git。

升级前后 28 项业务计数及配置、模型调用、媒体摘要完全一致。没有导入合成账号、测试目录或授权，新增资源策略表为空；默认挂载不自动取得授权。

正式 HTTP 逐字节核对 15 个 Web 制品与本地生产构建一致。资源策略查询、授权预览及确认接口均拒绝未登录请求（401）。Core、PostgreSQL、Hindsight 健康；独立 worker 心跳 ready，在线实例为 1。已有构建提示仍包括主包大于 500 kB；不影响本批构建通过，尚未进行分包优化。

独立 QA 环境在验证后清理；正式实例、数据库卷和资料卷保留。真实模型质量、150 题中文记忆评测、真实 QQ 登录及物理语音仍不在本批验收结论内。
