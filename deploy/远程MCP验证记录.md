# 远程 MCP 插件验证记录

版本：v1.27。日期：2026-10-30（Asia/Shanghai）。本记录说明本批实际验证结果，完整产品验收仍未完成。

## 实现范围

固定远程 Streamable HTTP MCP，支持初始化、协议版本协商、工具分页发现、工具目录快照、单独授权、调用预览确认、持久化执行及人工登记未知结果。连接和授权变化使旧预览失效；调用前重新发现并核对工具定义。

所有工具保守视为可能产生外部写入。发送标记先提交，再调用 `tools/call`；执行结果未知时禁止自动重发。工具文本与返回资源为外部数据，不执行其 HTML、链接或指令。密钥加密存储、会话标识不持久化，回显凭据的目录拒绝保存，调用结果脱敏。

## 隔离端到端验证

使用独立数据库、独立商店、合成账号和实际 HTTP 协议服务；未调用付费模型或真实第三方业务。

1. 发布者提交，经独立审核员审核、签名、同步、确认安装。
2. 保存加密连接，完成 MCP 初始化、会话头协商、分页发现和显式工具授权。
3. 经预览确认由 worker 调用工具，接收 SSE 结果并保存脱敏回执。
4. 服务收到 `tools/call` 后杀死 worker，重启并接管过期租约；结果保持待核对，远端调用计数未增加。
5. HTTP 503 保留未知副作用；人工核对登记不会触发重发。
6. 远端 Schema 改变后，旧授权及请求在 `tools/call` 前失效；重新发现和确认后才能继续。
7. Core／商店重启后，签名版本、加密连接、工具授权和回执保留。
8. 最终镜像实际调用一次成功，返回中不泄漏连接密钥或 MCP 会话标识。

JSON／SSE、UTF-8 分片、换行格式、响应大小与分页上限、Schema 引用、跨工作区拒绝、取消／撤权、备份恢复隔离等边界由专项测试覆盖。

## 页面与发布

已检查 375、768、1024、1440px 与矮屏滚动，工具授权、输入、预览、取消、Escape 和焦点返回。工具说明与 Schema 作为文本展示，授权勾选和逐次执行确认分别处理。

本机正式入口为 `http://localhost:8080`。更新前检查无运行中任务及有效语音会话，创建数据库备份并保留旧镜像，再升级到 `0022`。更新后原有业务数量、模型／策略／人格／语音配置的完整字段摘要一致，Core、PostgreSQL、Hindsight healthy，worker 在线，未登录的 MCP 接口返回 401。正式工作区未接入合成连接、测试信任根或测试插件。

## 尚未验证或实现

- 真实第三方 MCP 的兼容性、操作语义与费用，须逐服务接入验证。
- 不支持 stdio、本地执行程序、旧 HTTP＋SSE、OAuth、后台 GET 订阅、自动重连重放或远端客户端能力请求。
- API／MCP 未自动加入聊天或子助手工具调用链；角色包、事件适配器待开发。
- 独立商店完整备份及全产品灾备演练待完善。
- 中文长期记忆 150 题、真实语音质量、QQ 真实环境及全功能连续运行验收不由本批协议测试替代。
