# 语音协作使用说明（v1.71）

## 使用方式

在「智能对话」打开浏览器语音会话，使用手动录音或实时转写；结束转写后核对文字。普通语音保持普通聊天。需要自动分工时，明确勾选本条「助手协作」，核对范围后点击「确认发送」。连续对话不能委派，即使伪造手动确认字段也会被服务端拒绝。

授权仅用于当前一条消息，不从上次继承。目标最多 6000 字符，初始调用上限 12 次，可选 6／12／20／30 次；服务端范围为 3–30 次。主助手先判断直接处理还是委派，最多 8 个节点、3 个并发、1 层委派；独立分支并行，有依赖的分支串行，费用取决于实际模型调用。

| 选项 | 默认值及约束 |
| --- | --- |
| 共享相关记忆 | 关闭；只提供任务相关、当前有效且角色允许的 ContextBundle |
| 允许候选记忆 | 关闭；开启后也仅提交有来源候选，逐项核对确认才采纳 |
| 允许资料清单 | 关闭；还须服务器资源、角色和第一方插件授权有效，不读取用户电脑 |
| 远程工具 | 无选择；仅能选择已连接并授权的工具，每个远程请求仍需单独核对参数并确认 |

提交结果未知时，原转写、范围和请求编号固定，重试沿用同一请求。丢弃转写不会撤销可能已经创建的任务，先查看原会话卡片或任务中心。服务端幂等检查包含协作选项，不能借重试修改范围。

## 汇总与朗读

主助手通过已有持久化任务执行；子助手不分别联系用户。完成或部分完成后，主助手只写入一次原会话结果，并在原卡片关联。外部动作仍以真实回执核对，结构校验不等于模型内容全部正确。

原有效语音会话内显示「朗读汇总」，点击后才创建播放计划和调用 TTS。使用当轮冻结的语音设置和人格音色；开启新语音会话、结束、隐藏页面或断线都不自动补播。结束语音后服务器任务继续，用户可回原会话查看文字，取消任务使用任务自己的取消操作。

停止或播完的同一汇总不重放，重复点击不会创建第二个播放；已实际播完并上报的完整段落才进入语音听闻历史，未播完的段落不作为听闻事实。浏览器播放受限时需点击继续，继续前重新核对来源。

合成前、合成后、查询播放、恢复以及播放期间检查原消息、会话、任务、相关记忆、当前角色模型及资源授权。纠正、删除或撤销导致失效时停止后续读取和播报，合成中的迟到音频不再发布；前端运行时每秒核对一次，浏览器调度与网络可能延迟，已听到的声音无法撤回。

## 接口与迁移

沿用登录、所有者、工作区、CSRF、幂等和版本约束，不增加声纹授权或语音专用权限系统。

| 接口／字段 | 增量 |
| --- | --- |
| `POST /api/voice/sessions/{id}/messages` | 可选 `collaboration`，复用协作范围合约；仅手动且已确认转写可用，额外字段拒绝 |
| `GET /api/chat-actions` | 返回只对已确认语音协作有效的 `voice_result_message_id` |
| `POST /api/voice/sessions/{id}/playbacks` | 接收服务端持久化汇总消息 ID，拒绝浏览器自报汇总文本和其他语音会话 |
| 播放查询／音频／进度接口 | `collaboration` 标志及有效来源核验，停止收据不重放 |

业务数据库保存原 ChatRun、ChatAction、AgentRun 和唯一结果消息关联。`0055 → 0056` 只新增 `agent_runs.result_message_id` 索引；存在语音协作时不允许退回无法识别受保护汇总的旧 Core。需回退时使用升级前数据库、运行卷归档与配套镜像整体恢复，遵循现有删除及撤销重放流程。

## 验证范围

独立 PostgreSQL 相关回归 417 项、前端全量 423 项及类型检查、静态检查、构建通过。覆盖重复提交、范围冲突、连续模式拒绝、原会话约束、来源与角色撤销、合成中失效、停止后不重放、完整段落听闻和浏览器结束后任务继续。

隔离 HTTP→Nginx→Core→PostgreSQL→worker→本地 OpenAI 协议测试验证了两节点依赖、4 次规划／执行／汇总调用、唯一主助手结果和显式第 5 次 TTS 调用。Core 重启保留任务、结果、停止收据及已结束会话，不增加调用。独立数据库验证升级、无数据回退及有语音协作时阻止降级。

使用实际 VoicePanel、项目 CSS 和明确标记的合成转写替身验证 375／768／1024／1440px 布局、默认关闭的授权、Tab 顺序与未知提交后的固定请求；这部分仅为交互证据，不替代上述 HTTP 联调。未申请真实麦克风或系统通知权限，未调用真实模型或 QQ，真实识别、分工质量、物理播放体验和中文记忆质量仍待验证。
