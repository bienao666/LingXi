# 模型目录验证记录（v1.59）

验证日期：2026-11-01（Asia/Shanghai）。本记录仅覆盖模型目录路径修复、相关样式回归及本机部署，不代表模型推理、中文记忆质量或完整产品验收。

## 修复范围

- OpenAI 兼容目录严格使用配置的 API 根地址加 `/models`，不探测其他主机路径，不自动增加 `/v1`。
- API 根为 `/v1`、`/V1` 或自定义嵌套路径时保留大小写及路径；认证和限流失败不换路径重试。
- 添加模型继续根据所选连接自动加载，不恢复刷新目录或手动模型标识入口。用途验证仍独立执行。
- 媒体、语音及协作样式改用现有午夜蓝主题 Token；文件卡片最小宽度、视觉控件最小宽度和播放器上限保持原尺寸。
