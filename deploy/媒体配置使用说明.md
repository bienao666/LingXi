# 媒体配置使用说明

适用版本：v1.52，数据库迁移 `0046`。入口为“系统设置 → 媒体配置”；“数据日志 → 文件管理”保留同一附件策略入口，两处修改同一工作区配置。

## 类型和大小

允许类型可分别开启：纯文本 TXT、Markdown、CSV、文本 PDF、Word DOCX、Excel XLSX、静态图片（PNG／JPEG／WebP）和 QQ 语音消息。全部取消会关闭新附件接收及已有附件的新选择，不删除历史文件。

图片为一组能力，不分别开放 PNG 与 JPEG；QQ 图片的协议文件名归一化后仍需通过实际图片解码校验。QQ 语音指协议端转换后的 PCM WAV，不表示 Web 可上传任意音频。渠道开关、来源域名、权限、模型能力和更低的语音限制继续生效。浏览器麦克风、TTS 和 QQ 回复语音由原语音／渠道配置管理。

数量、单个大小和单条合计上限最高仍为 10 个、20 MiB／个、50 MiB／条，可调低。类型开关不会扩大解析器能力；未知格式、动画图片、扫描 PDF 专门 OCR、视频和图像生成不在当前解析能力内。页面提供实际解析方式和限制说明，不展示未生效的解析参数。

## 预览和确认

1. 点击“调整限制”，修改大小与允许类型。
2. 点击“预览变更”，核对原范围、新范围及影响说明；此时不保存配置。
3. 勾选影响确认，点击“确认保存”。成功后显示实际策略版本及反馈。

预览五分钟有效，绑定工作区、所有者、登录会话和配置版本。过期、其他窗口已修改或登录变化时重新预览。关闭、返回修改和 Escape 不保存。旧客户端仅修改大小而未传类型字段时保留当前类型，不能恢复已关闭格式；升级前产生的不含类型的旧预览须重新生成。

## 生效范围

Web 上传在接收前及入库前检查；聊天和子助手新选择的附件也在服务端检查。QQ 声明、接收排队、下载前后和音频转换／识别前检查当前配置。下载中关闭对应类型可能终止该次接收，清理尚未提交的暂存文件；已经发给上游的数据无法撤回。

已提交的模型任务继续使用原附件，不因关闭类型被追溯取消。已有文件可以按原权限查看来源及下载；重新选入新的对话或协作时须符合最新限制。类型配置不等于删除或隐私撤权；如需停止历史来源使用，应执行附件删除流程。

## 升级、备份与接口

`0046` 只为附件策略增加 `allowed_types`，为现有工作区保留原大小、数量、版本及全部既有类型。新工作区默认保持当前支持的全部类型。备份恢复保留最新类型限制并提升策略版本，旧预览失效。存在类型限制时拒绝直接降级，避免旧程序忽略限制；需要回退时使用升级前数据库与配套镜像。

复用 `GET /api/media-policy`、`POST /api/admin/media-policy/previews` 和 `PUT /api/admin/media-policy`。响应及预览增加 `allowed_types`，只接受固定类型标识，无脚本、路径或自定义 MIME 配置。身份与 CSRF 约定不变。

代码测试、实际容器和界面验收见[媒体配置验证记录](./媒体配置验证记录.md)。真实 QQ 和模型质量须独立验证。
