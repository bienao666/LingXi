# 短期情绪适配验证记录 · v1.41

> 本文保留 v1.41 历史证据；入口范围已由 [v1.54 情绪入口说明](./情绪入口使用说明.md)扩展，最新结果见[验证记录](./情绪入口验证记录.md)。

本轮在既有人格、支持偏好和真实聊天之上增加可选的短期线索。验证使用隔离 PostgreSQL、独立 Core／worker 和合成模型，不发送真实用户消息、不调用用户付费模型、不登录 QQ。真实中文情绪理解与完整 EMO 质量评测仍待验证。

## 使用入口与实际范围

“助手管理 → 支持偏好”保留倾听、建议、直接协助和自然平衡。自动情绪线索默认关闭，需明确勾选并保存；已有设置不会因升级而自动开启。开启前须配置已验证的记忆抽取模型。关闭适配或自动线索先展示影响确认，再保存生效。

只对未来新发的独立 Web 文字进行保守分析：第一人称、当前感受、最多 4000 字。引用、假设、角色扮演、他人、历史和诊断类描述跳过；QQ、语音、附件、任务和子助手不参与。单所有者至少间隔五分钟，每次最多 400 个输出 token，可能产生额外费用。未判断和失败有独立状态；超时、中断和未知结果不自动重试计费，不阻断普通聊天。

原文摘录必须连续存在于当前用户消息。结果区分“原文自述”“系统推测”“本人纠正”；不符合对应直接情绪词的结果降为推测。模型与词法检查都可能出错，标签不能作为疾病、人格或个人事实。没有回应、沉默和设备状态不用于判断心情。

线索默认一小时，可选一至四小时；只在原会话后续普通文字表达中使用，手填自述优先，不跨会话、分支、群聊或执行角色共享，不进入长期记忆和主动话题。新当前感受或明确否定使旧线索失效，即使本次因预算没有分析，也不沿用旧判断。

## 来源、纠正与失效

- 权威记录保存工作区、本人、原会话、源消息摘要、配置版本、固定模型及连接版本、证据类型和到期时间；不保存私有思维过程。
- 查询最近 50 条记录，可打开原会话、纠正、撤回和删除，修改均检查身份、CSRF 和记录版本。纠正不延长有效期。
- 偏好变化、来源删除、反馈、到期及授权失效清理摘录和标签；依赖它们的回答标为失效。部分失败／已停止的衍生回答同样清理，原始聊天另行管理。
- 生成逐段和提交前检查来源及配置，较晚返回的失效分析不能写回。撤回与纠正追加无正文的独立恢复屏障。
- 旧备份恢复先重放屏障；恢复隔离清空临时线索和手填当前感受，关闭自动分析，不恢复旧推测。普通偏好保留。

这套策略会使依据已失效线索生成的旧回答不可继续使用，需要重新提问。不会承诺撤回此前已展示、复制或交给外部模型的内容。

## 合约与部署

新增 `/api/emotion-observations` 查询、`/{id}/feedback` 纠正／撤回、`DELETE /{id}?version=...` 删除；沿用 `/api/support-preferences` 管理启用和有效期。模型调用用途记为 `emotion`，只记录版本、状态、耗时与用量；中断可能缺少完整调用回执，不代表没有费用；没有价格则费用未知。模型输出不能改变授权。

迁移 `0036` 新增临时线索表。空库可向下／向上迁移；已有记录或已开启自动分析时拒绝直接降级。回退使用升级前数据库备份、独立删除记录和匹配镜像；跨版本切换前须由支持新屏障的版本完成失效处理，不能假定旧执行器能理解新记录。

## 尚未完成

本轮没有实现情绪诊断、跨渠道自动情绪分析、全量情绪历史、原生实时语音、QQ 协作或通用文件产物执行。保守筛选会跳过部分真实表达；需真实模型、中文样本、误判纠正和用户体验评测，才能判断其理解能力。
