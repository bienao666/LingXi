# 长期记忆管理验证记录（v1.60）

验证日期：2026-11-01（Asia/Shanghai）。本记录覆盖分页管理、权威记忆过滤、召回顺序及本机发布；不代表真实模型、Hindsight 中文召回质量或完整产品已经验收。

## 变更范围

- 四类记忆页面按当前栏目分页查询，默认每页 50 条，候选支持状态筛选，导出和删除操作分别筛选，保留旧数组接口。
- 加密游标绑定用户、工作区、栏目、筛选与有效期；旧页仍读取当前纠正和删除状态，迟到响应不能覆盖新范围。
- MemoryService 保留索引相关性顺序，去重后按引用 ID 分批读取权威记录，核对身份、工作区、状态、到期、版本和索引代次，最多返回 12 条。
- 同页后台刷新保留已显示卡片；切换栏目或筛选后不展示旧范围。界面沿用现有主题、四字菜单和开机身份确认。
