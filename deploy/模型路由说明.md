# 普通聊天模型路由（v1.36）

在“模型管理 → 路由策略”先保存固定对话模型，再配置“自动选模”。默认固定模式、关闭降级，不迁移或修改既有真实配置。

1. 自动选模：按候选顺序筛选连接启用状态、当前验证版本、上下文预算，以及消息和历史图片的视觉验证。不按未经验证的价格或速度排序。
2. 候选第一项是固定对话模型；可增加五项已验证对话模型并调整顺序。没有满足条件的候选时明确失败。
3. 受控降级独立开启。固定模式可只开启降级；首选不可用时仍明确失败，不把固定模式变为自动选模。
4. 跨连接须另外允许；预览列出所有可能接收资料的服务地址、协议、模型、连接版本和配置的上下文容量。确认后生效，五分钟内有效。预览变化、版本冲突或地址变化必须重新核对。
5. 保存或关闭路由使尚在执行的旧路由回合停止；人格指定模型、任务协助、子助手、记忆抽取、Hindsight 网关及 ASR／TTS 保持固定模型与既有预算。

## 外发范围与能力

候选列表是明确允许接收当前问题、授权历史、记忆及附件的接收者集合。跨连接允许不表示可以使用集合外的服务，不因模型输出或外部资料扩大范围。QQ 采用频道所有者的路由授权，实际发言主体、群聊、记忆和投递对象仍使用原权限范围。

`allow_private` 只允许访问私网地址，不证明服务为本地模型。当前不提供地区自动证明或“只在本机”开关。资料有外发限制时，管理员必须仅选择符合其要求的接收端点，并核对系统代理路径。代理版本、固定策略、候选模型名、上下文配置、协议、连接地址或版本变化后，旧路由失效，重新预览授权；不会静默退回另一个接收者。临时停用或验证失效可由自动模式筛除，不能换成未授权型号。

所有调用保留统一加密凭据、系统代理、DNS 固定和不跟随重定向规则。上下文容量是配置值，UTF-8 预算为保守启发式，不宣称已验证供应商完整上下文。备用模型要求上下文不少于本轮首选、满足相同视觉要求；不重新裁剪资料、不删除图片。

## 降级规则

只有最终普通聊天回答在尚未输出任何文字时，遇 HTTP 429／502／503／504，或连接失败、连接超时、读取超时、远端协议中断，才可尝试一个已授权且仍可用的备用模型。HTTP 400／401／403／404／422／500、格式不兼容、空回答、来源失效、用户取消均不自动降级。空格也计作已开始输出，避免两段结果拼接。

最多两次最终回复调用；长历史压缩可能另有既有的一次固定模型调用。第一次超时仍可能产生费用，不能保证供应商取消计费，界面和日志保留失败记录；没有价格时显示费用未知。不会重新执行任务派发、历史压缩或任何工具副作用。

调用前持久化模型选择与 `calling` 屏障，模型记录、SSE `model_route` 事件和 ChatRun 保存实际模型及尝试序号。进程崩溃或作业重领不重放已运行回合；记录仍为 calling 时意味着结果未知，不能当作未调用。取消、记忆／附件删除、身份撤销、路由和提供商变更均在新请求前和接收输出时重新验证。

## 合约与回退

`GET /api/model-routing` 查询；`POST /api/model-routing/preview` 生成绑定身份、工作区、策略、代理和端点版本的短期 HMAC 预览；`PUT /api/model-routing` 校验版本和预览后保存。只有服务端认证身份能管理，主体不由浏览器自报。普通用途策略仍使用 `/api/model-policies`，嵌入索引不能自动切换。

迁移 `0031` 新增 `model_routing`；空表可回退至 `0030`，存在授权时拒绝丢弃版本屏障，使用升级前备份和配套镜像恢复。备份恢复继续禁用提供商并增加版本，旧路由保持失效直至重新授权。

隔离协议、数据库与浏览器验证不能证明真实供应商质量、区域合规、价格最优或中文记忆达标。费用／延迟排序、独立区域约束、任务／子助手多模型策略、语音原生路由仍为后续范围。

实际执行证据见 [模型路由验证记录](./模型路由验证记录.md)。
