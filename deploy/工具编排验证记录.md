# 工具编排验证记录

版本：v1.31。日期：2026-10-30（Asia/Shanghai）。本批仅扩展任务范围内、逐次确认的远程工具编排，不代表整个灵犀产品或真实供应商质量验收完成。

## 实现

Web 聊天“助手协作”和任务中心共用既有依赖编排器。角色声明 `plugin.call`，用户选择已连接授权的精确 API／MCP 工具；模型选择工具并生成严格 JSON 参数，先持久化等待确认。用户生成预览，核对实际地址、参数、费用和数据范围，再勾选确认执行。复用现有 API／MCP worker、持久化发送边界、脱敏回执和未知结果核对。

成功工具响应可交给直接依赖节点和主助手；外部文本只作资料，不授予权限或写长期记忆。工具、连接、目录、角色及来源在执行和结果提交前复核，包含下游模型进行中撤权的竞态。取消、记忆纠正和来源删除取消未发送请求、清除失效正文，不声称撤销已发生的外部操作。未知结果阻塞依赖和重试；人工核对不自动恢复失败链。

沿用午夜蓝、四字菜单、47 路由、十阶段身份门禁，不新增顶部介绍区或样式体系。共用弹窗修正嵌套 close 传播，并显式处理 Tab／Shift+Tab 边界循环。

操作、接口、限额与回退见[子助手协作说明](./子助手协作说明.md)。

## 隔离 HTTP／容器验证

使用独立 Compose 项目、数据库、商店、运行卷及合成模型／API 服务，不调用付费模型、不登录真实 QQ、不导入正式凭据。

1. 发布者提交，独立审核员审核签名，Core 同步及明确安装；独立连接、健康检查和合成模型协议验证通过。
2. 任务模型实际经 HTTP 规划和生成参数。无用户确认前，请求计数为零，依赖节点等待，不伪装执行。
3. Core／worker 重启保留待确认提案；新登录替换旧登录的预览，旧预览不能确认。
4. 重复确认只产生一次实际 API 请求，依赖分析再运行，主助手统一汇总；共四次合成模型调用，回执如实标明外部写入。
5. 合成 API 返回 503，记录 unknown；下游 blocked，任务失败，重试拒绝。同能力新预览也被未知写入屏障阻止。核对合成服务代码及请求计数后人工登记，才可开展后续测试。
6. 取消另一个待确认提案后，旧确认被拒绝，远程请求计数不增加。实际 MCP 链与超时、并发等边界由 PostgreSQL 全量中的协议专项覆盖；本批容器 HTTP 流程使用 API。

测试脚本曾发现合成模型未把 unknown 场景传给参数节点，修正测试服务后才验证失败分支；正常成功的那次不计为 unknown 验证。发现未知写入屏障生效后，先核对并登记合成记录，没有绕过屏障重复发送。
