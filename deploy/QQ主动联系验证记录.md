## 协议与持久化

使用独立 Compose 项目 `lingxi-proactive-qq-qa`、独立数据库／卷与合成账号，不复制正式配置或凭据。实际 HTTP 配置、双向私聊绑定、独立目标确认、认证反向 WebSocket、worker 到时检查和协议收发均通过。

合成 OneBot 对端接收一次 `send_private_msg`，返回匹配 echo／成功码／消息 ID 后，Core 记录“协议接受”并写入对应私聊会话。QQ 联系不再进入 Web 主动提示。断线前故意不返回第二次回执，Core／worker 重启并重连后保留“结果未知”，没有重放；核对只结束等待，随后明确停用联系保持有效。

专项覆盖：Web 默认兼容；未授权／未确认／无个人记忆许可／跨工作区／错误版本／群目标拒绝；固定 Web 会话与 QQ 互斥；离线无改投、有效重连及过期丢弃；静默和暂停；来源纠正删除、关闭、配置变化与绑定撤销；损坏／重复／迟到回执；超时、断线、失败和无重发核对；跨渠道额度及实际发送时间；取消一个话题不误取消其他话题；删除接续会话；私聊明确反馈；已核对的旧回复不永久阻塞新主动联系；单条 1500 字预算；旧快照恢复保留屏障、清除正文及关闭授权。

备份专项在隔离测试库模拟旧快照恢复；没有对正式库执行恢复。该测试不能替代全损灾难恢复、NapCat 登录资料恢复或跨服务器切换验收。

## 页面与可访问性

复用午夜蓝主题、既有表单／Modal，不增加菜单或恢复顶部介绍区。联系偏好展示目标、在线状态和授权范围；新目标预览默认未勾选，不能确认。联系记录区分排队、发送、协议接受、未知、失败、取消与人工核对，不将协议接受描述为送达或已读。

375／768／1024／1440px 检查无横向溢出；375×480 和 768×480 矮屏弹窗可滚动。Tab 边界留在弹窗，Escape 返回保存按钮；核对完成、原按钮消失时焦点返回联系记录标题。最终浏览器再次验证禁用背景；长目标标签采用可换行规则。
