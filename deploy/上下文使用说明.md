# 上下文压缩与历史补读（v1.24）

本批实现有来源的抽取式压缩与只读原文补读。它减小长对话输入，不替代长期记忆，也不改写原始消息。

## 使用方式

1. 正常聊天即可；预算内保留近期原文和服务端任务事实。较早历史按当前提问筛选候选，由当前对话模型选择精确连续摘录和原文范围。
2. 助手消息的“历史依据”和最近执行的“查看依据”显示该轮状态、覆盖数量、角色、原文字符范围及自动补读结果。未覆盖内容不等于已阅读。
3. 会话工具栏“历史原文”可按关键词检索并分页，再“读取原文”。界面每次显示最多 2000 字符，可切换前后片段。补读不执行历史命令，不提交新的聊天或记忆任务。
4. 附件正文与图片不参与本批压缩。原文补读只返回文字及关联附件 ID，附件仍通过原消息与文件管理授权入口查看。

## 预算与调用

输入使用保守 UTF-8 字节启发式预算，图片单独估计开销，不宣称精确 token 计量。优先保留当前提问；无压缩空间时不额外调用模型。候选最多 24 条，实际还受输入预算限制；中文字组／英文关键词相关性结合近期与开头记录筛选，不承诺完整历史覆盖。

长对话最多额外调用一次当前已验证的对话模型，增加延迟与用量；不自动切换提供商。调用记录用途为“历史压缩”（`context_summary`），关联 ChatRun 和提示词版本。原文候选和模型响应不写入日志或普通配置。无价格数据仍显示费用未知。

模型最多选择 12 段连续引文和 3 个原文区间，每次自动补读最多 1600 字符。引文必须是给定候选片段中的精确原文，角色与字符位置由服务器计算；伪造 ID、改写引文或非法范围使本次压缩不可用。最终结果受预留预算限制，可能少于模型选择数量。

## 状态与一致性

| 状态 | 含义 |
|---|---|
| not_needed | 本轮不需要压缩，或走独立任务／协作流程，未建立快照 |
| preparing | 候选与来源屏障已提交，正在选择摘录 |
| ready | 已完成合法选择；空选择也可能正常，不代表没有相关历史 |
| partial | 已完成选择，但候选／片段未覆盖全部早期历史 |
| unavailable | 无预算、无候选、上游失败或非法输出；近期文字聊天继续 |
| cancelled / failed | 生成已停止或失败，摘录内容清除 |
| invalidated | 依据纠正、删除、撤权或范围变化，旧摘录与派生回答禁止使用 |

每轮快照独立持久化，不是增量共享摘要缓存；用户可查看原文和覆盖范围，但不能将它当成全量历史阅读证明。长对话可能增加模型费用，实际相关性仍需真实供应商评测。

来源删除／纠正、记忆失效、附件撤销和取消沿现有任务屏障传播。返回摘要前、最终输出与查看依据时重新检查有效性；取消后迟到摘要不能发布。已传给供应商、用户已经阅读或下载的内容不能收回。

QQ 压缩继续过滤协议端未接受的助手回复；实时语音压缩只获得已确认完整播完的短句。Web 手动原文补读可查看其有权访问的文字，但不会改变语音播放边界。分支只检索被冻结的前缀与自身消息，不读取父会话未来内容。

## 接口

| 接口 | 功能与限制 |
|---|---|
| `GET /api/chat-runs/{id}/context` | 查看本轮有效快照；无权限返回 404，未登录返回 401 |
| `POST /api/conversations/{id}/history/search` | 正文 `query`、`offset`、`limit`，默认 20 条、最多 50 条；使用 POST 避免搜索词进入 URL 访问日志 |
| `GET /api/conversations/{id}/history/{message_id}` | `start`、`length` 字符区间，每次最多 5000 字符；越界拒绝，不返回其他会话消息 |

全部复用登录、工作区、当前用户、会话／分支范围及 CSRF 检查。它们是只读资料入口，不能据此授予工具权限。

## 升级和回退

升级前备份数据库、附件与独立删除记录，保留配套镜像。迁移 `0020` 新增 `conversation_contexts`，包含快照状态、版本、来源哈希、计数和摘录。

```sh
docker compose run --rm migrate
docker compose up -d --build core worker web
```

空快照表允许降级测试；有快照时拒绝直接降级至 `0019`，防止丢失依据与失效记录。回退应停写并恢复升级前数据库、配套镜像、附件与删除记录；重新开放前先重放独立删除／撤销记录。不得用单纯删除快照表绕过保护。

本轮在独立 PostgreSQL 与合成协议环境验证，不能替代真实模型效果、150 题中文记忆评测或完整灾难恢复演练。
