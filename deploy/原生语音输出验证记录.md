# 原生语音输出验证记录（v1.58）

本次增量只验证“已确认核心回复 → 原生 Realtime 逐句音频 → 字幕核对 → 播放回执”，不代表完整双向实时语音已经交付。

## 已验证

- 独立实时输出配置、能力验证和配置版本／供应商版本绑定；没有配置或未验证时不会调用原生输出。
- `conversation=none` 的响应请求、音频分片收集、PCM WAV 封装、输出字幕去空白严格匹配，内容不一致时丢弃音频。
- 既有 VoicePlayback 的来源、顺序、人格音色、登录、会话、播放游标和消息状态在生成前后复核；停止或迟到结果不推进 `offered_parts`。
- 上游错误、超时、格式异常、过大音频和模型拒绝只产生一次失败记录，不自动重试普通 TTS，不重复提交聊天或记忆。
- 前端仅在实时合成已验证时选择原生输出路径，原有普通 TTS 作为未配置时的基线；错误不会静默改变语音模式。
- 前端新增三项路径回归：未验证使用普通 TTS，已验证使用 `/native-audio/0`，原生失败不请求普通 TTS。
- 独立 Docker QA 使用 `lingxi-native-output-qa`，通过 `127.0.0.1:8082` 的 Nginx→Core→Realtime 夹具完成登录、语音会话、回复来源、原生音频返回、播放回执和脱敏调用记录核对。
- 独立后端专项 7 项通过；原有语音与实时转写相关回归 71 项通过；前端全量 346 项通过（含 3 项原生输出路径测试），类型检查和构建通过。
- 全量后端回归 1813 项通过、32 项按环境跳过；生产 Docker 已完成 v1.58 更新，迁移仍为 `0050`，Core／worker／Web 健康，旧镜像标签为 `pre-v158`，数据库备份为 `.preview/lingxi-pre-v158.dump`。
- 生产入口 HTTP 检查通过：Web 返回 200，未登录身份和原生输出接口返回 401；部署前后 30 类业务计数及配置／调用／媒体摘要一致。隔离 QA 容器和临时凭据已清理。

## 待验证

实际供应商的原生音频输出、中文音色自然程度、首段延迟、打断时的真实播放位置、不同浏览器的 PCM 播放设备，以及原生模型直接回答仍待验证。当前协议夹具只证明边界和安全约束。
