# QQ 异步语音输入验证记录

版本：v1.34；日期：2026-10-30；数据库迁移：`0029`。

本批实现 QQ 语音输入、后台 ASR 与原会话文字回答。测试使用独立数据库、合成 OneBot 对端、PCM 音源及本地模型协议服务；未登录真实 QQ、未向联系人发送消息、未调用付费模型。实际缓存键格式、NapCat 转码结果、中文识别准确度与真实账号体验仍待验证。

## 实现范围

- 渠道规则新增默认关闭的语音接收开关，保存前预览；沿用绑定、群白名单与触发、去重、限流和同目标顺序。语音与图片／直链文档开关独立。
- 复用所有者已启用且验证的 ASR、代理和全局音频预算，不因 QQ 语音启动浏览器录音、会话或扬声器。每分钟每所有者最多 30 次音频调用。
- 核对固定 NapCat `v4.18.41` 的消息转换、缓存标识和 `get_record` 源码。仅接收受支持的 32 位十六进制缓存键及 amr／silk／slk／wav 后缀，不接受路径、URL、任意字符串或 CQ 指令；其他格式明确失败，仍需真实账号适配验证。
- 已认证反向 WS 上持久化请求后取音频，限定当前连接、未完成 echo、来源与期限；只读 `data.base64`，忽略返回的本机路径与 URL。转换等待 60 秒；重复／迟到／旧连接回执不重复落盘或创建识别作业。
- 每消息最多一段语音、10 个总附件、50 MiB 总量；音频最多 6 MiB、0.1–60 秒、16 位 PCM、1–2 声道、8–48 kHz，校验完整帧。普通入站消息仍限制 64 KiB；只有音频回执允许有界大帧。
- 统一 Media 保存转换后的 WAV，来源注明不含原始 SILK／AMR；未经确认的转写以附件证据进入聊天，可查看／下载／删除。含语音的整条消息不自动抽取记忆；抽取端也拒绝重投的旧作业。
- 使用既有会话主体、模型、相关记忆检索、权限和来源链。群聊及非共享私聊隔离，全部附件完成后才回答；无工具或子助手执行入口。只向原 QQ 会话回复文字，协议接受不表示送达、已读或已听。
- worker 付费调用前持久化 `calling` 屏障，崩溃恢复、超时和错误不盲目重复 ASR；未知时如实说明。撤权、配置变化、原会话／音频删除、恢复隔离影响在途及未发送内容。含语音记录时阻止直接降级丢弃屏障。

## 自动验证

- Linux 容器＋独立 PostgreSQL 完整后端：**1,081 项通过**，734.82 秒。此后仅细化转换后 WAV 文案、下载标签及语音记忆抽取屏障；相关集 **266 项通过**，204.93 秒；最终新增重投屏障后的语音＋核心集 **74 项通过**，51.75 秒。最终完整后端未再次整套重跑。
- 最终 Windows／SQLite QQ 语音专项：**58 项通过**，55.39 秒。此前既有渠道、附件、浏览器语音相关集 **117 项通过、1 项 PostgreSQL 专属跳过**；Linux 相关集不跳过该并发场景。
- 最终前端整套 **192 项通过**；TypeScript、47 路由／四字菜单／10 阶段开场静态检查、本地及 Docker 构建通过。Vite 仍提示主 JS 包超过 500 kB，未发生构建失败；后续可单独拆包。
- 空库 `0029 → 0028 → 0029` 通过；含语音记录降级被拒绝。Core／商店 OpenAPI、92 个运行时源文件／合约哈希、新增列及索引与运行环境一致。

专项涵盖默认关闭、未验证 ASR、绑定和群触发、隔离与越权、缓存键校验、重复消息、精确回执、非法 base64／波形、时长和体积、混合附件失败、同目标排序、超时和断线、付费预算、调用中崩溃、来源和模型配置变化、发送前删除、转写不入记忆、重投抽取防护及未知错误脱敏。

## 实际网络与界面

独立 Compose 项目 `lingxi-channel-audio-qa` 通过实际 HTTP 登录、配置模型、完成 ASR 接口验证及 QQ 双向身份确认。认证反向 WS 接收超过 64 KiB 的合法 WAV 回执；worker 启动前持久化波形及作业，重启 Core 后启动 worker，完成 ASR、统一聊天与原目标投递。核对重复事件不再次调用模型、没有记忆抽取、删除后无法下载且关联回答失效。最终镜像另以新消息编号重验 HTTP／WS／worker 链路。

界面检查 375、768、1024、1440px，以及 375×480、768×480 矮屏。表单可滚动、无文档横向溢出；预览焦点、Tab 循环、Escape 和焦点恢复通过。服务更新期间身份页明确显示连接失败，可重试恢复有效会话。来源页明确显示未经确认的转写、转换 WAV 说明和“下载音频”，不自动播放。

## 发布与限制

本机正式入口 `http://localhost:8080` 已升级至 schema `0029`。升级前 `.preview/lingxi-pre-v134.dump` 已保存并通过 pg_restore 目录核验，Core／worker／Web 保留 `pre-v134` 配套镜像。16 类原有业务数量及模型／连接／用途／人格／音色加密配置摘要一致，未导入隔离测试身份、渠道、语音配置或音频，未启用实际 QQ 语音权限。

正式运行的 92 个源文件／合约哈希、Core／商店 OpenAPI、新增列和索引与最终代码一致；Web JS／CSS／开场资源与本地最终构建一致。Core／数据库／Hindsight 健康，worker 在线；未登录接口保护及 Nginx 请求限制核验通过。

隔离测试容器、网络、数据库卷和运行卷已移除，临时 QA 环境配置文件已清理；脚本、日志、截图和升级前备份保留，原有 `.preview/preserved-live-experiment` 未变动。

本批不含 QQ TTS／音频回传、实时语音、通用语音工具执行、其他缓存键自动适配或实际模型质量验收。完整 30＋10＋10 语音体验评测、150 题中文记忆质量及真实 QQ 连续运行仍待完成。用户音频仅在管理员明确开启渠道规则后，发送给已配置的 ASR 服务；日志、收发元数据和错误不含音频、转写或缓存键。
