# 系统配置中心

适用版本：v1.50；迁移 `0044`。通过 Web“系统设置 → 系统配置”管理基础默认值；现有代理表单保留。

| 配置 | 生效范围与优先级 |
|---|---|
| 空间名称 | 1–40 字，保存后同步当前标签页侧栏；其他标签页重新加载可见 |
| 默认时区 | 有效 IANA 时区，如 `Asia/Shanghai`；仅为尚未单独设置的联系偏好提供默认值，已有联系偏好和提醒不改动 |
| 默认人格 | 当前所有者本工作区启用的人格或内置并肩伙伴；仅用于选择“继承工作空间”的会话；显式会话选择优先 |
| 历史预算 | 1500–48000 UTF-8 字节，作用于新聊天回合和重新生成的历史选取与压缩；模型更低上限优先；不是 token 或完整请求预算 |

已提交的聊天固定配置版本、预算及实际人格版本；修改默认值不会重启、取消或重新执行任务。旧的显式人格选择继续有效；没有选择的会话继承默认值。可切换到“内置 · 并肩伙伴”避免继承，也可再选择“继承工作空间”。独立 QQ 发送者不会继承所有者私人人格；绑定与资源授权仍由原入口管理。

## 修改与版本

1. 编辑基础默认值，点击“预览更改”。此时没有保存。
2. 核对每项旧值、新值和影响说明，在 5 分钟内点击“确认生效”。
3. 查看当前版本与配置历史。相同预览只能成功一次；并发更改、会话失效、人格修改或停用后需重新预览。

配置没有差异时不会创建空版本。历史分页展示，每次读取 20 条。回退点击历史中的“预览回退”，仍需核对和确认；回退创建新版本，历史版本号不会倒退。历史引用的人格已停用、已失效、越界或偏好模型不可用时，不能直接回退，应先选择有效人格。

导入导出采用以下完整格式；不接受额外字段和隐式类型转换。

```json
{
  "format": "lingxi-workspace-defaults/v1",
  "config": {
    "workspace_name": "个人工作空间",
    "default_timezone": "Asia/Shanghai",
    "default_persona_id": null,
    "history_budget_bytes": 48000
  }
}
```

导入文件限 16 KiB，或粘贴 JSON。导入只生成预览，不能绕过确认；跨工作区的人格 ID 不会自动绑定、复制或授权。导出只含四个字段及格式标识，不导出人格正文、模型密钥、连接、代理、插件或联系许可；其他设置沿用专属入口。

## 接口与恢复

| 接口 | 用途 |
|---|---|
| `GET /api/system-settings` | 读取当前版本、基础配置与更新时间 |
| `POST /api/admin/system-settings/previews` | 使用 `edit`、`import` 或 `rollback` 单一来源生成差异预览 |
| `PUT /api/admin/system-settings` | 提交预览令牌和 `new_turns_only` 确认声明 |
| `GET /api/admin/system-settings/revisions?before=…` | 版本倒序读取；返回 `next_before` |
| `GET /api/admin/system-settings/export` | 白名单格式导出 |

所有接口要求真实登录；写入复用 CSRF／Origin 校验。预览令牌绑定用户、工作区、登录会话和当前版本，不写浏览器存储；确认时按锁重新检查，审计只记录动作和版本，不存正文。

备份恢复保留恢复前最新基础配置与历史、创建新版本，并清空默认人格引用，防止将旧档案中的人格重新应用。联系、模型、插件、语音、账号和删除记录继续遵守恢复隔离。已有配置历史或继承选择时禁止有损降级；使用升级前备份和配套镜像恢复。

本次不包括完整跨模块导入、模型／插件授权恢复、渠道配置打包和系统迁移面板。真实供应商、长期记忆中文质量及物理语音的验收状态不会因配置中心上线而改变。
