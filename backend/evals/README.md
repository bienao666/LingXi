# 中文记忆评测

`memory-150.jsonl` 包含 150 个不同问题：事实偏好 30、事件项目 25、更新时态 25、主体引用假设 20、未知争议 20、删除 15、重启重投递 15。`dataset.py` 为可复现源文件。

必须在**独立且为空的评测部署**初始化 `eval-lingxi` 所有者，配置真实模型与 Hindsight，再执行：

```sh
python backend/evals/run.py --base-url http://localhost:8080
```

脚本交互读取密码，不写入报告。测试资料会发送给部署中已配置的模型服务。脚本只接受专用账号和空部署；逐题创建测试数据并清理，不针对日常个人数据运行。

本数据集测量用户确认资料的检索、来源、更新和生命周期。抽取质量由独立的原文／主体／引用回归测试及人工样本审查检验，不能用检索得分冒充抽取质量。重启场景要求操作者实际重启服务；未知、争议和删除后的自然语言回答须人工审查，不能仅靠关键词判断无依据断言。

报告按题保存真实回复与状态；`needs_review` 不是通过。完整质量门槛仍按设计方案：前五类 ≥90%，未知／争议无依据断言 ≤5%，删除和恢复断言全通过。没有真实模型、容器或人工判分时，报告保持“待验证”。
